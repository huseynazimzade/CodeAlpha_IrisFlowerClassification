\## Task 1: Iris Flower Classification



The goal of this project is to classify Iris flowers into three species

(setosa, versicolor, virginica) based on their measurements.



\### Dataset

\- Iris flower measurements (sepal length, sepal width, petal length, petal width)

\- 150 samples, 3 classes



\### Approach

\- Loaded and explored the dataset using Pandas

\- Visualized feature distributions with Seaborn

\- Split data into 80% training and 20% testing

\- Trained a Logistic Regression model using Scikit-learn

\- Evaluated the model with accuracy score and classification report



\### Results

\- \*\*Accuracy: 100%\*\*

\- The model correctly classified all test samples



\### Libraries Used

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn
